# Joaoapps Join (HACS)

Custom integration that replaces the core `joaoapps_join` component.

- Add via **Settings → Devices & services → Add entry**: enter your Join API key, then pick devices.
- Provides `<name>_ring`, `_send_url`, `_send_file`, `_set_wallpaper`, `_send_sms`, `_send_tasker` actions and `notify.<name>`.

## Install
1. HACS → ⋮ → **Custom repositories** → add `https://github.com/surge919/hass_join_update` as **Integration**.
2. Download, restart Home Assistant.
